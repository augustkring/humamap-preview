# HumaMap site preview

This folder mirrors the current production homepage from `augustkring/humamap` and is the public static workspace for the next website pages.

## Structure

- `site/index.html` — current homepage baseline
- `site/styles-base.css` — shared approved visual system
- `site/styles.css` — launch polish / spacing / accessibility layer
- `site/individuals/` — next Individuals page
- `site/businesses/` — next Businesses page
- `site/leadership/` — next Leadership page

## Branch mapping

- Production/development source: `augustkring/humamap` → `site-pages`
- Public visual preview: `augustkring/humamap-preview` → `site-pages`

Main branches stay untouched while page work is in progress.
