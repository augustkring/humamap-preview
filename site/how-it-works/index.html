Method

A common framework for every HumaMap.

HumaMap Core organises work context across CAN, WILL and HOW. The framework draws on established work in occupational psychology. It is not a new personality model.

CAN

What you bring.

Capabilities, knowledge, experience and learning capacity.

WILL

What moves you.

Motivation, ownership, priorities and direction.

HOW

How you work.

How you execute, communicate, collaborate and lead.

More context when useful. Recognised assessments, such as Big Five instruments, can add evidence based information. Reflection frameworks can add another perspective. HumaMap keeps those sources separate.
