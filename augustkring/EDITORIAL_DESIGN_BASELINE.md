# August Kring — Approved Website Baseline

Approved 2026-10-10. Tested by `node augustkring/verify-baseline.mjs`.

**Protected homepage:** hero, the verbatim Where I add value summary, the Waymaking narrative, My current focus, The shift I see, the personal signoff/contact block, and footer. The homepage story is digest-locked to prevent unnoticed edits.

**Design defaults:** one shared `styles.css` in Outfit/Figtree, white background, navy typography, restrained red accent, 1080px content width and responsive gutters. Reusable typography, colour, spacing, measure, radius, surface and focus values live in `:root` tokens. Story-section rhythm: desktop clamp(72px,6.8vw,92px), mobile 58px. Contact: one cohesive personal signoff block on every viewport; desktop keeps the contact actions directly beneath the name in one inline row, while mobile stacks the same actions vertically. No isolated right-hand action rail, third column, centred text island, extra cards or decorative gradients.

**Writing basis:** WR-00 v2 (preserve and diagnose), WR-01 v2 (truthful value and claims), WR-02 v2 (accurate chronology and causal limits), plus user-approved eight mindset/skillset dimensions. Professional evidence: August Kring — Erfaring & CV-grundlag. Do not equate self-reported Big Five with unvalidated reflection frameworks.

**Preview metadata policy:** intentionally `noindex,nofollow`. Production canonicals and social imagery still target augustkring.com, currently a separate Danish website. Check social portrait asset and canonical/OG URLs before production-domain cutover. Newsletter uses `/api/subscribe`, which is not verified as working on static GitHub Pages.

**Update policy:** Any future homepage change needs explicit approval plus reviewed updates to the guard values. Digest is a regression sentinel, not security.
