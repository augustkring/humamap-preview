# Open-source foundation

This website deliberately uses copied, editable open-source source code as its visual and interaction foundation rather than recreating a design from screenshots.

## 7Ovr shadcn-next-starter
- Source: https://github.com/7Ovr/shadcn-next-starter
- License: MIT
- Role: Next.js, Tailwind, Base UI/shadcn primitives, accessibility and project foundation.

## 7Ovr SaaS Landing
- Source/install: `pnpm dlx shadcn@latest add @7ovr/saas-landing`
- License: MIT-0 for the free template.
- Used verbatim as the source for the header, hero, pricing, FAQ and CTA layout systems before BLENTERA copy/brand adaptation.

## 7Ovr SaaS Landing 2
- Source/install: `pnpm dlx shadcn@latest add @7ovr/saas-landing-2`
- License: MIT-0 for the free template.
- Used verbatim as the source for the tabbed feature system, stepper and comparison layout before BLENTERA copy/brand adaptation.

The BLENTERA implementation removes the original demo brands, fake proof, testimonial/logowall sections, generic integrations and template-specific product claims. BLENTERA-specific copy and product framing are derived from the BLENTERA Master Deck v28.
